## API 假设与边界
- 所有业务数据读取 /api，使用 cookie credentials include，snake_case 字段直接映射，无演示指标或成功兜底。
- 登录恢复 401 返回登录页；已登录业务请求失败直接展示错误。业务成功后重新读取 dashboard。
- 支付幂等键稳定为 qingxing-order-{订单编号}，服务器必须保障唯一支付与积分事务。
- 工单完成状态 COMPLETED；未完成且已分配工单可提交结果，实际权限由服务器审核。
- 员工编辑发送 id，为主任务确认的合同扩展；dashboard staff 已包含 email，可自动预填员工编辑邮箱。
- /api/report 返回 HTML；/docs/ER图.svg 需要主服务器静态文件支持。
- 碳数据明确标注模拟；路线为米制本地示意路网，不使用真实 GPS 或支付。
- 地图尺寸按站点坐标与半径自适应，覆盖既定六个种子停车区（最大坐标 850,750）。
- 不增加依赖；字体使用本地系统字体，地图无需网络图片。
