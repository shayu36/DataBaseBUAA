# 学院路校区地图与停车点借还车设计

地图最初考虑用百度地图在线底图。随后发现北航官网已发布 2026 年学院路校区平面图，包含建筑、道路、绿园、体育区与家属区，故改用该官方图作为本地底图，无须百度 AK。停车点、路线和禁行范围为课程模拟覆盖物；后端沿用局部坐标计算围栏与路线。不得将旧版人工方格路网继续展示为真实道路。

校内所有可见道路按课程模拟规则允许骑行，包含西侧家属区内部道路；主楼至三号教学楼步行核心区和图书馆入口步行区为禁行区。禁行范围在地图中明显显示，穿越禁行范围的路段不得被路径算法使用，停车点也不得位于禁行范围内。图层以停车点、可骑行道路、禁行区和任务为主；学生、管理员和运维员沿用现有角色化信息。

学生借车先选停车点，再选该点可借车辆；还车只选停车点与路线偏好。地图点选只能选停车点，不再暴露或编辑 x/y。后端在模拟还车请求缺少位置时从已选停车点读取中心坐标，在同一事务中执行既有围栏、容量、路线、结算校验；显式位置请求继续用于测试与设备定位场景。历史订单、支付、积分和还车证据不被重算，升级地图时拒绝覆盖自定义图及有活动骑行/调度的数据库。

底图来自[北航学院路校区页面](https://www.buaa.edu.cn/xygk/xydt1/xylxq.htm)的[2026 年校区平面图](https://www.buaa.edu.cn/images/xylxq20261013.jpg)。校园图来自官网，停车点位置、路线成本及禁行边界均是课程模拟数据，不能当作官方停车许可或实测导航。

验收：地图展示官网学院路校区平面图和明确建筑标注；家属区路网可达；六处停车点在禁行区外；路线不使用 NO_RIDE 边；学生借还车不需要输入坐标；完整订单、支付与积分数据保留。
