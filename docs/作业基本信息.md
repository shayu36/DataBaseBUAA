# 校园共享自行车系统数据库设计

系统名称：青行 Qingxing。小组成员：贾鑫洋、欧阳晨、郑一凡、王奕。

项目面向校园借车、电子围栏归还、模拟支付、调度与维修，使用 MySQL、Express、React 实现可操作的业务闭环。八个业务实体为用户、自行车、停车区、骑行订单、支付记录、运维人员、调度任务、维修工单。十一项命名联系为创建订单、使用车辆、当前停放、骑行起点/终点、支付结算、执行调度、调出/调入、包含车辆、提交报修、发生故障、负责维修。两项双角色各拆为两条边，共十三条实际联系。

逻辑实现为18表：8核心实体表、1任务车辆关联表、9支持表；另有4视图、2触发器、1采样存储过程。七创新均有可执行闭环：多条件热点分析、可追溯调度建议、可处置风险预警、有向路网三方案推荐、可复核追加式碳积分、自愿公开排行榜、带定位新鲜度的电子围栏复核。地图、定位、道路属性、支付和碳减排均明确为教学模拟，风险为可解释规则。
