# 测试与验收说明

测试应在本机 MySQL 已启动且 `.env` 配置完成后执行。`npm test` 会重建 `campus_bike_test` 的测试数据；浏览器测试会在业务演示库中产生测试记录。

交付包筛选测试使用 `uv run python -m unittest discover -s tests -p package_project_test.py`，在临时目录验证配置文件、日志、符号链接及凭据扫描，不修改现有交付包。

```text
npm run build
npm run format:check
npm test
npm start
npm run test:e2e
npm run check
```

浏览器测试需要另一个终端中保持 `npm start` 运行。备份与恢复需要本机 `mysql`、`mysqldump`，操作步骤见项目根目录说明。

2026-10-27 进一步复用覆盖时长查询已读取的快照计算数量，在隔离库对 259,200 条快照交替运行三轮：旧版为 7.742、7.803、7.760 秒，新版为 7.308、7.357、7.279 秒；每轮曲线和统计结果一致。该对比为本机样本，不代表生产并发性能。

## 风险刷新样本性能
